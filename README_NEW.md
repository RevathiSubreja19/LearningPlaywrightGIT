# LearningPlaywrightGIT

Minimal repository for learning Playwright and practicing JavaScript/TypeScript.

Contents
- `new.js` — sample script
- `JAVASCRIPTLearning/` — many JavaScript practice files grouped by chapters
- `tests/` — Playwright test examples

Getting started

1. Install dependencies (if needed):

```bash
npm install
```

2. Run Playwright tests (if configured):

```bash
npx playwright test
```

Notes
- This repo includes practice code and example Playwright specs. Edit or run files from the project root.
- For TypeScript files, use `ts-node`/`tsx` or compile via `tsc`.
